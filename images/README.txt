This folder is reserved for photography and raster image assets
(e.g. site photos, camera product shots, technician photos).

The current build uses inline SVG technical diagrams instead of
stock photography, so no real business or client photos are
implied. Drop optimized JPG/WebP files here (e.g. hero-rack.jpg,
technician-cabling.jpg) and swap them into the <figure> elements
in index.html / about.html when real project photography is
available, for a more photographic look alongside the diagrams.
